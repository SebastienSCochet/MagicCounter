# MagicCounter

Application Android (Kotlin, architecture MVP) qui compte les points de vie des joueurs pendant une partie de jeu de cartes à collectionner : dégâts, types de points, événements de partie et préférences.

## Pistes d'amélioration

- Migrer vers Jetpack Compose et `java.time` à la place de Joda-Time.
- Ajouter l'historique de partie et la gestion de plus de deux joueurs.
- Ajouter des tests sur `Game` et `EventManager`.
